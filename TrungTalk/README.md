# TrungTalk Android V1.0

Native Kotlin + Jetpack Compose app based on the supplied Trungtalk.docx.

Included:
- 12-month curriculum with five phases and lesson content.
- Persistent completed-lesson progress using DataStore.
- Mandarin text-to-speech with normal and slow playback.
- Starter Chinese-Vietnamese flashcards.
- Speaking recognition through the Android speech recognition service (device/service support required).
- Progress summary and the three learning principles.
- AI integration status screen.

Package: com.trungtalk  
Minimum Android: 7.0 / API 24  
Target SDK: 34

AI chat, advanced pronunciation scoring, Room-based Leitner scheduling, gamification, offline Gemma, listening service and Wear OS are not claimed as operational in this first APK. AI needs a deployed Cloudflare Worker and server-side secrets.
